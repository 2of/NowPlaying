This app is just a nice now playing view for android phones. The TLDR is my car doesnt have Bluetooth controls for media while driving and I recently purchased a samsung phone. The 'next' and 'play/pause' targets are too small when driving to be safe to use with a car mount.

So heres' this. It's a bit quick and dirty. I was trying to mimic the effect of the play/pause button on MetroList (YTM client) so there's some custom code to make that happen with jetpack compose.

You can use samsug routines to tie an nfc tag to opening (and closing) this app. Works for me.
